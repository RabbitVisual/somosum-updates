# Release Notes — SOMOSUM 8.7.11

**Data:** 2026-07-29  
**Tipo:** feature (Ferramentas · MIDI · PowerPoint)

## Destaques

### PowerPoint nativo (sem Office)
- **Ferramentas → PowerPoint…** importa `.pptx` (OOXML) direto para a **ordem do culto**.
- Não precisa do PowerPoint instalado nem de tela estendida.
- Cada slide vira parte de um item **Apresentação** e avança com ← → no Ao vivo (Stage/Remote seguem o Controle).
- Opcional: criar louvor com o texto extraído dos slides.

### MIDI no culto
- **Ferramentas → MIDI…** — pedais/teclados via Web MIDI.
- Learn por mapa (nota/CC → próximo, anterior, tela preta, logo, limpar).
- Preferência salva; reconecta ao abrir o Controle se estiver ativo.
- Opção de ação pela intensidade (velocity / valor CC).

### Menu Ferramentas
- Removidos os itens “Em breve” de MIDI e PowerPoint.
- Badge de hint do menu no tema escuro (sem bloco branco ilegível).

## Como atualizar
1. Abra o SOMOSUM → **Ajuda → Verificar atualização** (ou aceite o convite ao abrir).
2. Baixe, confirme o reinício e aguarde o app reabrir.
3. Confira a versão **8.7.11** em Painel → Sobre.
