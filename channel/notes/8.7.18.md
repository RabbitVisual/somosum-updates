# Release Notes — SOMOSUM 8.7.18

**Data:** 2026-07-30  
**Tipo:** hot-fix (legibilidade em vídeo claro + auditoria tipografia)

## Destaques

### Texto legível em vídeo/imagem claros
- Em **todos** os tipos de slide: **Sombra**, **Contorno**, **Placa (preenchimento)** ou **Nenhum**.
- Controle **Escurecer fundo** (0–75%) — útil quando o vídeo de fundo atrapalha a leitura.
- Posição vertical (topo / centro / base) no mesmo bloco de tipografia.

### Cores onde faltavam
- **Louvor**: cores de título e letra no inspetor.
- **Mensagem**: cores de tema, texto e referência + legibilidade.
- **Bíblia**: fundo do slide + mesmos controles de legibilidade.
- **Ceia**: cores/fonte do inspetor passam a valer (não ficam mais “travadas” no visual da ceia).

### Ajustes globais (Ajustes → Projeção)
- Preferência **Texto sobre vídeo claro** (sombra / contorno / placa / véu).
- Slider de **intensidade do véu**.

## Como atualizar
1. **Ajuda → Verificar atualização** → **8.7.18** → confirme o reinício.
2. Painel **Sobre** deve mostrar **8.7.18**.

## Verificação rápida
- [ ] Louvor com vídeo claro: Escurecer fundo + Contorno → letra legível no projetor
- [ ] Bíblia / oração / seção: mesma opção de Texto legível
- [ ] Mensagem: chips de cor Tema / Texto / Ref. ao vivo
- [ ] Ceia: mudar cor do título no inspetor → projetor acompanha
- [ ] Ajustes → Projeção: mudar padrão global e reabrir o projetor
