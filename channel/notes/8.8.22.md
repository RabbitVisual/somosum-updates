# SOMOSUM 8.8.22 — Letras profissionais (estilo Holyrics)

### Divisão correta (fim das quebras irregulares)
- Linha em branco = fronteira de estrofe: verso e refrão **nunca** misturam no mesmo slide
- 4 linhas por slide = 4 linhas poéticas na tela (como Holyrics)
- Soft-wrap opcional no inspetor (padrão: desligado)

### Legibilidade na projeção
- Novo padrão **Contorno + sombra** (texto nítido em qualquer fundo)
- Contorno, sombra, placa ou nenhum — no inspetor de Louvor
- Escurecer fundo + espaçamento entre linhas (compacto → amplo)

### Sistema mais limpo
- Uma única lógica de divisão (sem duplicar regras)
- Limpeza de colagem unificada
- Import Holyrics (.muf/.mufl) continua suportado

### Como usar
- Louvor → inspetor → Tipografia e divisão / Legibilidade
- Reaplique a letra ou use “Formatar slides” no editor da biblioteca se a música antiga ainda misturar estrofes
